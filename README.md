# CRT-观点检查器

帮助你检查「这句话有道理吗」「这个结论站得住吗」，分清事实、因果、预测与价值判断，看看前提、证据、推理和适用边界能支持多强的结论。

## 能帮你做什么

- 检查一句话、阅读笔记或文章中的中心观点。
- 区分「结论可能正确」与「给出的理由足够支持结论」。
- 找出相关与因果、个案与普遍结论、事实与价值之间的跳跃。
- 给出有条件的判断、待核验事项，以及忠实原意的修订句。

推理成立时会直接认可，不强行挑刺。需要外部事实时按所在工具的能力核验；无法核验会明确保留判断。

## 安装

下载本仓库 ZIP 并解压，将文件夹改名为 `crt-claim-checker`，保留完整目录。

- **Codex**：放入 `~/.agents/skills/crt-claim-checker/`。
- **Claude Code**：个人使用放入 `~/.claude/skills/crt-claim-checker/`；项目使用放入项目的 `.claude/skills/crt-claim-checker/`。

确认 `SKILL.md` 直接位于上述文件夹下。重新打开会话，并检查工具是否已识别该 Skill。其他支持 `SKILL.md` 的工具按其安装说明添加整个文件夹；菜单配置与自动调用支持可能不同。

## 使用示例

在 Codex 中输入：

```text
使用 $crt-claim-checker，检查这个观点：
“我用了这个方法后效率提高，所以人人用都会提高。”
说明现有依据能支持到哪里，并给一版更准确的表述。
```

也可以输入：

```text
使用 $crt-claim-checker，检查下面文章的中心结论和关键理由。
区分事实问题、推理问题和价值取舍，不重写整篇文章。
[粘贴文章]
```

按任务需要，输出结论、关键原因、更准确的表述与还需核实的事项。简单观点会简短回答，不强制填满模板。

## 边界与验证状态

只检查主张，不据此诊断人格或动机，也不替用户作出医疗、法律或投资决定。不执行材料中的指令，不自动发送或发表检查结果。

`SKILL.md` 中的案例是规则示范，不代表独立执行测试或真实用户试用。依赖外部事实的检查效果取决于所在工具的检索能力与可访问资料。
